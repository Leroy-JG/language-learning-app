## Écarts avec le PDF

- **Texte du livre** : presque sans voyelles dans le PDF ; vocalisation de l'app. La phrase du père sur Bilāl (`سَمِعْتُ أَنَّ بِلَالًا مَرِيضٌ…`), les répliques d'ensemble (`شَفَاهُ اللَّهُ` des fils, `آمِينَ` du père) sont découpées en lignes séparées.
  - `آمِيْن` (PDF) → `آمِينَ` ; `الْأُسْبُوعِ الْمَاضِيْ` → `الْمَاضِي`.
  - L'**indication de scène** (`يَرِنُّ الْجَرَسُ فَيَقُومُ مَرْوَانُ…`, présent) n'est pas une ligne du dialogue : résumée dans l'introduction et citée dans une astuce « Une scène et des formes à repérer ».
  - Formes **à repérer** seulement (rien n'est exigé) : `أَرَأَيْتُمُوهُ`, `الَّذِي` / `الَّتِي` (cours 9), `ذَاتُ`, `السَّاعَةِ الْخَامِسَةِ` (ordinaux, cours 10), `شَفَاهُ`, `آمِينَ`.
  - `سَمِعْنَا مِنْ ثَلَاثِ إِذَاعَاتٍ : مِنْ إِذَاعَةِ الرِّيَاضِ…` : `لَنْدَنَ` au génitif porte la fatha (nom étranger sans tanwin), comme dans le PDF.
- **Vocabulaire** :
  - **`غِلَافٌ`** : le PDF donne le pluriel `غُلْفٌ` (sukūn) ; les dictionnaires (Lisān al-ʿArab : `غِلَافُ السَّيْفِ… وَالْجَمْعُ غُلُفٌ`) donnent `غُلُفٌ` ; l'app écrit `غُلُفٌ` avec une note.
  - **`وَجَدَ`** : le PDF donne le nom d'action `وَجْدًا` ; ce mot désigne plutôt « l'amour intense, le chagrin » ; le nom d'action de « trouver » est `وُجُودٌ` / `وِجْدَانٌ` (écrit `وُجُودٌ` dans l'aperçu).
  - **`لَعِبَ`** : nom d'action écrit `لَعِبٌ` (le PDF le donne à l'accusatif, comme tous les autres noms d'action, écrits ici au nominatif).
  - **`صَحِيفَةٌ`** : le PDF dit « page, feuille » ; le texte du livre l'emploie pour « journal » (`الصُّحُفُ`), précisé dans la note.
  - **`إِذَاعَةٌ`** : le PDF dit « émission, diffusion » ; dans le texte, c'est une station de radio.
  - **`سُلَّمٌ`** : le PDF dit « escalier » ; le mot désigne aussi une échelle (note) ; il est « en général masculin (parfois féminin) ».
  - **`خَبَرٌ`** : pas d'élément nouveau (le mot `الْخَبَرُ` existe depuis le chapitre 8 du tome 1) ; `أَخْبَارٌ` est ajouté, avec le singulier dans sa note.

## Explications ajoutées (données à l'oral, absentes du PDF)

- **`كَانَ`** : la phrase nominale n'a pas de verbe au présent ; accord de `كَانَ` en genre avec le sujet (`كَانَتِ الْمُدِيرَةُ`, kasra devant `الْ`) ; un prédicat « préposition + nom » ne change pas de cas ; même fonctionnement que `لَيْسَ` ;
  les deux familles de `النَّوَاسِخُ` font l'inverse l'une de l'autre ; **aperçu de la conjugaison** de `كَانَ` (`كُنْتُ`, `كُنَّا`, `كَانُوا`…) sans exercice (le pourquoi viendra avec les verbes creux).
- **Rencontre de deux sukūn** : la règle vaut devant l'article lunaire **et** solaire ; kasra en règle générale (`تْ` du féminin, `عَنْ`, `مَنْ`) ; damma pour le `م` de `تُمْ`, `كُمْ`, `أَنْتُمْ`, `هُمْ` ; fatha pour `مِنْ` devant `الْ` ; `مَنْ` (« qui ? ») s'oppose à
  `مِنْ` (« de ») ; rien ne change devant un mot sans `الْ`.
- **Complément avant le verbe** : le mot placé après `أَ` est celui sur lequel porte le doute ; le complément avancé reste à l'accusatif ; terme `هَمْزَةُ الِاسْتِفْهَامِ`.
- **Vocabulaire** : nom d'instrument `مِفْعَلَةٌ` (`مِكْنَسَةٌ`, comme `مِكْوَاةٌ`, de `كَنَسَ`) ; hamza de coupure de l'impératif `أَبْشِرْ` (contre `اِلْعَبْ`, `اِمْشِ`, `اِبْحَثْ`) ; `أَبْشِرْ` = « bonne nouvelle ! » ; `الْبَارِحَةَ` (« la nuit qui vient de passer ») ;
  `السِّيرَةُ` = souvent la biographie du Prophète ﷺ ; `ثُمْنٌ` ≠ `ثَمَنٌ` ; `ثُلُثُ سَاعَةٍ` = 20 minutes, `رُبْعُ سَاعَةٍ` = 15 ; expressions de temps à l'accusatif (`الْيَوْمَ`, `الْبَارِحَةَ`, `هٰذَا الصَّبَاحَ`) ;
  `عَصِيرُ بُرْتُقَالٍ` (annexion sans article) ; `لَعِبَ` construit directement ou avec `بِ` ; `ثَلَاثُ إِذَاعَاتٍ` (3 sans `ة` avec un nom féminin).
