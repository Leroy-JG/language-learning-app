## Écarts avec le PDF

- **Fautes de la diapositive corrigées** : `ضَرَبُ زَيْدٌ يَاسِرًا` (damma sur le `ب` du verbe) → `ضَرَبَ` ; `الْمَفَاعِلِ` (nom des compléments) non repris, l'app dit
  « les cinq `الْمَفَاعِيلُ` » ; `أُقْتُلْ` (tableau des verbes) → `اُقْتُلْ` (hamza de liaison, damma car le présent est `يَقْتُلُ`).
- **Noms d'action** : écrits au nominatif (`فَهْمٌ`…) ; le PDF les donne à l'accusatif (`فَهْمًا`…).
- **`فَتَحَ` et `قَرَأَ`** ne figurent pas dans le tableau du PDF : leurs quatre formes sont ajoutées dans l'aperçu (`يَفْتَحُ / اِفْتَحْ / فَتْحٌ`, `يَقْرَأُ / اِقْرَأْ / قِرَاءَةٌ`).
- **Exemples du tableau de vocabulaire** remplacés par des exemples simples, car ils contiennent des mots non enseignés : `الْبَقَّالُ يَعْمَلُ فِي الْبَقَّالَةِ` (présent,
  `بَقَّالَةٌ`), `هَذَا جَوَابٌ صَحِيحٌ` (`صَحِيحٌ`), `قَتْلُ الْحَيَّةِ سُنَّةٌ` (`سُنَّةٌ`). `أَكَلْتُ تِينًا` et `كَسَرَ زَيْدٌ عَصَاهُ` sont repris.
- **`حَيَّةٌ`** : le PDF dit « vipère » ; le mot désigne un serpent en général (Lisān al-ʿArab) : traduit « un serpent », avec une note.
- **`جَمُلَ`, `كَبُرَ`** : le PDF ne les traduit pas ; « il est beau », « il a grandi ».

## Explications ajoutées (données à l'oral, absentes du PDF)

- **`لَازِمٌ` / `مُتَعَدٍّ`** : « attaché » / « qui dépasse » (de `تَعَدَّى`).
- **Nom après une préposition** : n'est pas un complément d'objet direct (génitif) ; `دَخَلَ` se construit sans préposition.
- **Cinq `الْمَفَاعِيلُ`** (note de `w:maful-bih`) ; marques de l'accusatif des pluriels réguliers (`◌ِينَ`, `◌َاتِ`) ; accusatif invisible d'un nom maqṣūr (`عَصَاهُ`).
- **Pronoms compléments** : mêmes formes que les pronoms collés aux noms, sauf « me » = `نِي` (nūn de protection) ; le pronom suit le genre du mot arabe (`الْبَابُ` → `هُ`) ;
  un pluriel de choses est repris en général par `هَا` ; le pronom complément collé reste collé au verbe, avant le sujet nom (`ضَرَبَكَ زَيْدٌ`).
- **Un seul sujet par verbe** : verbe en tête au singulier (aussi au duel : `ذَهَبَ الطَّالِبَانِ`) ; accord en genre, le plus souvent au féminin avec un sujet féminin ;
  avec un pluriel féminin, le masculin singulier est aussi possible (Coran 60:12, `إِذَا جَاءَكَ الْمُؤْمِنَاتُ`) ; deuxième verbe repris par un pronom ; l'alif muet de `◌ُوا` tombe devant un
  pronom collé (`قَتَلُوهَا`) ; `ذَهَبَتْ` → `ذَهَبَتِ` devant `الْ`.
- **Vocabulaire** : modèle `فَعَّالٌ` des métiers ; noms collectifs de fruits et leur unité (`تِينَةٌ`, `عِنَبَةٌ`, `مَوْزَةٌ`, `تُفَّاحَةٌ`) ; `حَيَّةٌ` féminin pour les deux sexes ;
  `عَصًا` féminin sans signe ; `جَمُلَ` / `كَبُرَ` (modèle `فَعُلَ`, qualité naturelle) ; sourates Al-Fajr (89ᵉ) et At-Tīn (95ᵉ), 114 sourates ; règle de la voyelle de la hamza de liaison de l'impératif
  (`اُقْتُلْ` / `اِغْسِلْ` / `اِسْمَعْ`) ; `لِأَنَّنِي` / `إِنَّنِي` et `لِأَنِّي` / `إِنِّي`.
