## Écarts avec le PDF

- **Exercice 9** : les phrases 1 (« نص الفصل ١٩ طالبا » : probablement `نِصْفُ الْفَصْلِ`, mais le support écrit `نص`), 4 et 8 (« 20 ») sont
  **omises** (les dizaines ne sont pas enseignées avant le cours 10). Les six autres sont reprises ; la phrase 2 est une seule phrase
  à deux trous (`خَمْسَةَ عَشَرَ` accusatif invariable, `اثْنَا عَشَرَ` nominatif : second sujet de `عِنْدِي`).
- **Exercice 4** : phrases 4 (« اللغة العربية / سهل / اللغة الفرنسية »), 7 (« الرجال / كثير / النساء ») et 9 (« الموز / رخيص / العنب ») **omises** : les deux
  premières posent une affirmation discutable (surtout la 7, qui contredit l'exemple du tableau d'expressions
  `النِّسَاءُ أَكْثَرُ مِنَ الرِّجَالِ عَدَدًا`) ; la 9 emploie deux mots (`مَوْزٌ`, `عِنَبٌ`) non enseignés.
- **Exercice 5** : la phrase 7 (« الأزهر جامعة قديمة في العالم » → « أَقْدَمُ جَامِعَةٍ فِي الْعَالَمِ ») est **omise** : elle ferait écrire qu'al-Azhar est la plus
  ancienne université du monde, ce qui n'est pas établi (al-Qarawiyyīn, à Fès, est souvent citée comme plus ancienne). Les autres phrases sont reprises
  en « phrase de départ → phrase transformée », avec la locution finale (`فِي حَيِّنَا`…) dans la phrase de départ.
- **Exercice 3** : les dix phrases sont reprises (traduction, remplissage, ordre, dictée) ; le livre donne `أُولَئِكَ` et `ذاك` sans voyelles : lus
  `أُولَئِكَ` et `ذَاكَ` (formes de l'app).
- **Texte du livre** :
  - presque sans voyelles dans le PDF ; vocalisation de l'app (le PDF note `غُرَفَهُ`, `نَوَافِذَهُ`, `مَرَاحِيضَهُ` à l'accusatif après `إِنَّ`, et `السُّرُرُ`
    au nominatif : reprise telle quelle, c'est le début d'une nouvelle phrase nominale) ;
  - la suite de points après `فِي فَصْلِنَا` n'est pas reprise (pas de « … » dans un texte arabe) ;
  - `ولكنَّ حامداً` : le PDF écrit `وَلَكِنَّ` (sans alif) : même graphie ;
  - `ما شاء الله` : `مَا شَاءَ اللَّهُ` ; `أدفترك هذا` : `أَدَفْتَرُكَ هٰذَا` (« est-ce ton cahier ? ») ;
  - `الْمَهْجَعِ الْخَامِسِ` / `الثَّامِنِ` : nombres ordinaux, cités en aperçu (rien n'est exigé) ;
  - `أَيُّهُمَا` traduit « lequel des deux », `مَهْجَع` « dortoir ».
- **Verbes** : `جِيئَةٌ` (nom d'action de `جَاءَ`, donné par le PDF) est repris, avec la mention de `مَجِيءٌ` (nom d'action courant) ; `رَ` (impératif
  de `رَأَى`) et `رُؤْيَةٌ` / `رَأْيٌ` / `رُؤْيَا` sont repris tels quels. Seul le passé est exigé (présent et impératif : aperçu).
- **Pluriels** repris du PDF : `خُطُوطٌ`, `أَجْزَاءٌ`, `مَنَامَاتٌ`, `كَوَاكِبُ`, `أَشِقَّاءُ`, `فُرَقَاءُ`, `لَاعِبُونَ`. `سِنٌّ` : le PDF ne donne pas de pluriel.
- **Genre** : `سِنٌّ` est **sans `gender`** : féminin pour « dent » (Lisān, Wasīṭ), mais pour « âge » les dictionnaires (Lane) donnent aussi le féminin sans trancher ; à confirmer avec le professeur.
- **Pluriel `فُرَقَاءُ`** (`فَرِيقٌ`) : repris du PDF (Langenscheidt le donne aussi) ; un relecteur ne connaît avec certitude que `أَفْرِقَةٌ` / `فُرُقٌ` : à vérifier dans le Lisān.
- **Faute d'orthographe du support** : `نص` (exercice 9, phrase 1) ; le PDF met aussi `ولكنَّ` sans alif dans la bulle de dialogue (graphie courante).

## Explications ajoutées (données à l'oral, absentes du PDF)

- **« Dix » s'accorde de 11 à 19, il contredit tout seul (3 à 10)** : `عَشَرَ` / `عَشْرَةَ` ici, `عَشَرَةُ` / `عَشْرُ` dans `عَشَرَةُ كُتُبٍ` / `عَشْرُ سَيَّارَاتٍ`.
- **Douze** : le premier morceau se comporte comme un duel dont le `ن` est tombé (`اِثْنَا` au nominatif, `اِثْنَيْ` à l'accusatif et au génitif) ; troisième
  exemple (`إِنَّ فِي الْفَصْلِ اثْنَيْ عَشَرَ طَالِبًا`) pour l'accusatif.
- **`التَّمْيِيزُ`** : un nom indéfini, singulier, à l'accusatif ; il sert après `كَمْ`, après 11 à 19 et pour dire « en quoi » on compare (`أَكْبَرُ مِنِّي سِنًّا`).
- **Le comparatif, moule `أَفْعَلُ`** sur les trois lettres de la racine (`طَالَ` → `أَطْوَلُ` : le `و` revient ; `وَاسِعٌ` → `أَوْسَعُ` : le `ا` disparaît).
- **Invariable avec `مِنْ`** (masculin / féminin, singulier / pluriel) ; avec un pronom : `مِنِّي`, `مِنَّا` (le `ن` se fond).
- **Superlatif** : comparatif + nom indéfini singulier au génitif (annexion) ; le nom s'accorde avec la personne ; comparatif suivi de `مِنْ` : plus… que…
- **Sans tanwin** : fatha au génitif quand le comparatif est seul ; retour de la kasra comme premier terme d'annexion (`بِأَعْلَمِ طَالِبٍ`) ou avec l'article
  (déjà enseigné au tome 1, chapitre 23) ; `لَيْسَ زَيْدٌ أَعْلَمَ مِنْ مُحَمَّدٍ` (sans `بِ`) aussi correct.
- **`لَكِنَّ`** : sœur de `إِنَّ` (nom à l'accusatif, prédicat au nominatif), entre deux phrases de sens opposé ; avec les pronoms `لَكِنَّنِي` / `لَكِنِّي`,
  `لَكِنَّكَ`… ; ne pas la confondre avec `لٰكِنْ` (sans shadda).
- **`كَأَنَّ`** : vient de `كَ` + `أَنَّ` ; même effet que `إِنَّ`.
- **`بَلَى` / `نَعَمْ`** : `نَعَمْ` confirme ce qui précède ; après une question négative elle confirmerait la négation, d'où `بَلَى`.
- **`مَا شَاءَ اللَّهُ`** : marque d'admiration, rappelle que ce qui arrive est voulu par Allah.
- **`مَنَامٌ`** vient de `نَامَ` ; **`مَهْجَعٌ`** de `هَجَعَ` ; **`لَاعِبٌ`** de `لَعِبَ` (comme `لُعْبَةٌ`, `مَلْعَبٌ`).
- **Verset Yūsuf 12:4** (`إِنِّي رَأَيْتُ أَحَدَ عَشَرَ كَوْكَبًا`) : l'exercice 9, phrase 3, le reprend.

## Pas encore enseigné (donc sans exercice)

Les dizaines (`عِشْرُونَ`…), les nombres ordinaux (`الْخَامِسُ`, `الثَّامِنُ` : cités dans le texte), le présent et l'impératif de `جَاءَ` / `رَأَى` (aperçus),
`الَّذِي` / `الَّتِي` (aperçu), `سَلَّمَ عَلَى`, le superlatif avec l'article et le féminin du comparatif (`الْكُبْرَى`, `الْأَكْبَرُ`), `عَنْ` en dehors de
`بَعِيدٌ عَنْ`, le complément d'objet (`مَسْجِدًا` après `رَأَيْتُ`, cité en aperçu).

## Corrections faites après la relecture (3 relecteurs : arabe, exercices, français et pédagogie)

- **Explication fausse** : « مِنْ + ي donne مِنِّي » corrigé en `مِنْ` + `نِي` (le `ن` de protection) ; même logique ajoutée pour `لَكِنَّنِي` / `لَكِنِّي` (`grammar-9`).
- **Généralisations** : « tous les noms de la forme `أَفْعَلُ` n'ont pas de tanwin » (faux pour `أَسَدٌ`, `أَرْنَبٌ`) → « les adjectifs (couleurs, comparatifs) et les prénoms comme `أَحْمَدُ` » ;
  « le comparatif ne change jamais » → « de genre ni de nombre » (sa voyelle finale change : `بِأَعْلَمَ`) ; le superlatif s'accorde avec ce qu'il désigne (un seul sujet ici) ;
  « le second terme sans tanwin prend la fatha » complété (avec l'article : kasra, `مِنَ الرِّجَالِ`) ; `أَعْلَمُ طَالِبٍ` traduit « l'étudiant le plus savant » (et non « des étudiants »).
- **Vocabulaire** : « morceau » remplacé par « partie » dans tout le chapitre (mot du professeur, et `جُزْءٌ` est enseigné).
- **Réponses justes ajoutées** : `أَطْوَلُ` pour « plus grand que lui », réponses sans `سِنًّا`, `وَهُوَ أَيْضًا`, `فِي السَّمَاءِ نُجُومٌ`, ordres de mots avec `أَمْسِ` en tête, ordre alternatif de `بَيْتِي أَبْعَدُ…`.
- **Distracteurs** : `كَوْكَبٌ` n'a plus « étoile » ni « lune » comme faux choix ; `أَكْبَرُ` (bilan) n'a plus `أَطْوَلُ`.
- **Notions exigées sans être enseignées** : les phrases du livre avec `الثَّامِنُ` / `الْخَامِسِ` et `الَّذِي` sont posées en français seul (`practice-5`).
- **Revue** : deux exercices hors dialogue ajoutés à `practice-5` (le planificateur de révision ignore les exercices liés à un dialogue).
- **Notes d'oral ajoutées** : astuce « une seule des deux parties porte le `ة` » (13 à 19), `مَا شَاءَ اللَّهُ` (Coran 18:39), `بَلَى` (Coran 7:172, peut suivre une phrase négative non interrogative), prononciation de `لَكِنَّ`.
- **Notes d'éditeur retirées de l'app** (restées dans ce fichier) : phrase 7 de l'exercice 5, phrases omises de l'exercice 4, suite de points du dialogue ; `سَلَّمَ` est de la Révision 2 (plus un aperçu).
- **Gardé** : `السُّرُرُ` au nominatif (reprise du PDF, l'accusatif est aussi correct, noté dans l'app) ; `جِيئَةٌ` (attesté dans le Lisān) avec `مَجِيءٌ`.
