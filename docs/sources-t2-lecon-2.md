## Écarts avec le PDF

- **Faute du PDF (exercice de conjugaison)** : le modèle donne `أَنَا أَكَلْتُ … هُوَ كَتَبَ ، هِيَ كَتَبَتْ …` (les formes de `كَتَبَ`
  recopiées de l'exemple précédent) et oublie `نَحْنُ` : l'app donne la ligne complète de `أَكَلَ` (`أَكَلَ`, `أَكَلَتْ`, `أَكَلَا`,
  `أَكَلُوا`, `أَكَلْنَ`, `أَكَلْنَا`), signalée dans une note.
- **Numérotation des exercices** : le PDF a les exercices 1, 2, 3, 5, 6, 7, 8 (pas de 4) ; dans l'exercice 5, la phrase (8) manque.
  La phrase (10) (`الطَّالِبَاتُ فِي الْمَكْتَبَةِ`) est **omise** : `مَكْتَبَةٌ` (« une bibliothèque ») n'est pas enseigné.
- **Exercice 2, phrase (6)** : le PDF écrit « أبو مسلم » (sans pronom, contrairement aux autres phrases `أَخَوَاتُهُ`, `أَبْنَاؤُهُ`…) ;
  lue `أَبُوهُ مُسْلِمٌ` (« Son père est musulman », faux d'après le texte).
- **Exercice 8** : (3) le PDF écrit `رِيَالً` avec une fatha : écrit `رِيَالٍ` (second terme d'annexion après `مِائَةُ`, génitif) ;
  (6) le PDF écrit `الْمِصْرِفِ` (kasra sur le `م`) : écrit `الْمَصْرِفِ`, comme dans le tableau de vocabulaire ; l'exemple du tableau
  `فِي جَيْبِي مِائَةُ دِينَارٍ` devient `مِائَةُ رِيَالٍ` (`دِينَارٌ` n'est pas enseigné).
- **Prénoms** : ce texte met en scène **Hishām** (`هِشَامٌ`, vocalisé dans le PDF) et **Bilāl**, pas Hāshim (leçon 1).
- **Vocalisation** : le texte du livre est presque sans voyelles. Choix de lecture :
  - `إِنَّ بَعْضَهُمْ تُجَّارٌ وَبَعْضُهُمْ مُهَنْدِسُونَ` : le second `بَعْضُهُمْ` est le sujet d'une nouvelle phrase nominale (nominatif) ;
    l'autre lecture (`وَبَعْضَهُمْ`, coordonné à `بَعْضَهُمْ`) est aussi correcte ;
  - `نِيُويُورْكَ` : la vocalisation de ce nom étranger est celle de l'app (le PDF ne note que la kasra du `ن`) ;
  - `مَنِ الْأَخُ؟` traduit « Qui est ce frère ? » ; `وَالْحَمْدُ لِلَّهِ` traduit « louange à Allah » ;
  - les points de suspension après `بِلَالُ بْنُ حَامِدٍ` ne sont pas repris (pas de « … » dans un texte arabe).
- **Exercice 1** : les trois questions sont posées en saisie avec toutes les réponses justes (avec ou sans `هُوَ` / `إِنَّهُ`) ;
  « D'où vient Hishām ? » accepte `نِيُويُورْكَ` comme `الْوِلَايَاتُ الْمُتَّحِدَةُ`.
- **Exercices 3, 5, 6, 7** : `بِ` devant le prédicat de `لَيْسَ` est facultative : les deux tournures (`لَيْسَ بِطَالِبٍ` et
  `لَيْسَ طَالِبًا`) sont acceptées partout, avec ou sans le sujet rappelé dans les réponses aux questions.

## Explications ajoutées (données à l'oral, absentes du PDF)

- **Pourquoi un sukūn avant le pronom** : l'arabe évite d'enchaîner quatre voyelles brèves dans un même mot (`كَتَبَتُ` → `كَتَبْتُ`).
- **Voyelle de `ت` à la 2e personne** : même voyelle que le pronom isolé (`أَنْتَ` → `تَ`, `أَنْتِ` → `تِ`) ; ressemblance des terminaisons
  `تُمَا` / `تُمْ` / `تُنَّ` avec `أَنْتُمَا` / `أَنْتُمْ` / `أَنْتُنَّ`.
- **L'alif après `وا`** est écrit mais non prononcé (`كَتَبُوا` = « katabū »).
- **Duel féminin** : `كَتَبَتَا`, `لَيْسَتَا` (le PDF ne donne que `كَتَبَا` pour `هُمَا`).
- **Un nom apparent après le verbe n'appelle pas de pronom pluriel** : `خَرَجَ الطُّلَّابُ`, `خَرَجَتِ الطَّالِبَاتُ` ; avec le nom avant, la phrase
  est nominale et le verbe reprend le sujet : `الطُّلَّابُ خَرَجُوا`.
- **Un pronom collé du nominatif est invariable** (`مَبْنِيٌّ`) : ses voyelles distinguent les personnes, pas les cas.
- **`لَيْسَ`** : verbe sans présent ni impératif, conjugué comme un passé, traduit par un présent ; le `ي` tombe devant un pronom commençant
  par une consonne (`لَسْتُ`, `لَسْنَ`) ; `بِ` devant son prédicat ne se traduit pas et renforce la négation ; pas de `بِ` devant « préposition + nom » ;
  `لَيْسَ لِي إِخْوَةٌ` : `لِي` est le prédicat (placé avant), le nom qui suit est au nominatif.
- **Le passif** (note de `grammar-1`) : le verbe passif ne nomme pas celui qui agit ; étudié plus tard.
- `إِنَّ لِي ثَلَاثَ أَخَوَاتٍ` : l'ordre d'origine est `إِنَّ ثَلَاثَ أَخَوَاتٍ لِي` (le prédicat « préposition + pronom » est avancé) ; le sujet
  groupe « nombre + dénombré » met son premier mot à l'accusatif.

## Pas encore enseigné (donc sans exercice)

Le complément d'objet (`الدَّرْسَ`, `الْبَيْتَ`, `زَيْدًا`… : cités en aperçu, signalés dans les astuces), le présent et l'impératif
(les quatre formes de `ضَرَبَ` et `دَرَسَ` sont un aperçu), `كَانَ` et les autres sœurs de `كَانَ`, les pronoms collés de l'accusatif
(cases du schéma laissées « à venir »), les pronoms isolés de l'accusatif (`إِيَّاكَ`), le passif.
