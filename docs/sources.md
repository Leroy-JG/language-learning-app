# Sources et choix de contenu

Ce fichier garde la mémoire du contenu : d'où vient chaque leçon, ce qu'elle enseigne (une leçon
suivante ne peut s'appuyer que sur ce qui est déjà enseigné), et les choix faits quand l'app
s'écarte ou complète les supports du professeur. **À mettre à jour à chaque leçon.**

interdit la modification et l'usage commercial de ses supports. Pour une nouvelle leçon, demander à
l'utilisateur de joindre les PDF dans la conversation.

## Ce qui est déjà enseigné (cumulatif)

**Leçon 1** (`l01`) :
- les trois sortes de mots : nom, verbe, particule (définitions des grammairiens) ;
- le verbe : passé, présent ou futur (المُضَارِع), impératif ;
- هٰذَا (singulier, masculin, proche ; choses et personnes) ;
- pas de verbe « être » dans la phrase nominale ;
- l'alif suscrit (هٰذَا) ;
- les questions avec أَ, مَا (chose, animal), مَنْ (personne) ;
- les réponses نَعَمْ et لَا ;
- le tanwin = « un / une » ;
- les premiers pluriels (vus comme vocabulaire).

**Leçon 2** (`l02`) :
- ذٰلِكَ (éloigné) ;
- وَ (et) ;
- أَذٰلِكَ ؟ ;
- le classement des mots connus : noms interrogatifs et démonstratifs, particules interrogative, de réponse et de coordination ;
- les noms de matière (« du sucre », « du lait »).

**Leçon 3** (`l03`) :
- indéfini (نَكِرَةٌ) et défini (مَعْرِفَةٌ) ;
- le tanwin : son nom, ses trois formes, les noms propres, la pause ;
- l'article الْ, qui fait perdre le tanwin ;
- la phrase « le stylo est cassé » (adjectif attribut) ;
- la hamza de liaison :
  - en début de phrase ;
  - après وَ ;
  - مَنِ devant l'article ;
  - الِاسْمُ ;
  - la différence avec la hamza coupante ;
- les lettres lunaires et solaires (avec la shadda) ;
- le genre des noms :
  - ة marque le plus souvent le féminin, et sa prononciation (t / h) ;
  - les parties du corps qui vont par paire sont féminines pour la plupart.

**Leçon 4** (`l04`) :
- الْإِعْرَابُ : la terminaison change selon le rôle du mot (trois voyelles finales, avec ou sans tanwin) ;
- les prépositions (حُرُوفُ الْجَرِّ) :
  - فِي عَلَى مِنْ إِلَى avec leurs sens ;
  - le nom qui suit prend en général la kasra (◌ُ → ◌ِ, ◌ٌ → ◌ٍ) ;
  - مِنْ devient مِنَ devant l'article ;
  - le ى final de عَلَى et إِلَى ;
- la phrase sans verbe « nom défini + préposition + nom » (الْكِتَابُ عَلَى الْمَكْتَبِ) ;
- أَيْنَ (invariable) et مِنْ أَيْنَ ;
- les pronoms هُوَ هِيَ أَنَا أَنْتَ (et أَنْتِ, signalé) : ce sont des noms définis, هُوَ / هِيَ suivent le genre du nom remplacé ;
- les noms propres (الْعَلَمُ) et les quatre sortes de noms définis vues jusqu'ici (nom propre, démonstratif, avec الْ, pronom) ;
- le tanwin (définition, marque du nom) et plusieurs marques du nom, dont trois sont citées (tanwin, article, pouvoir suivre une préposition) ;
- les noms privés de tanwin (مَمْنُوعٌ مِنَ الصَّرْفِ) :
  - la plupart des noms propres féminins, et les pluriels de forme « longue » (مَدَارِسُ, مَرَاحِيضُ…) ;
  - ils prennent une fatha après une préposition (فِي مَكَّةَ) ;
  - les noms étrangers en alif long ne changent pas à l'écrit (فَرَنْسَا) ;
- les noms de lieux en مَ (اِسْمُ الْمَكَانِ), repérés dans مَسْجِدٌ مَكْتَبٌ مَطْبَخٌ مَدْرَسَةٌ ;
- le verbe خَرَجَ et le verbe ذَهَبَ (passé, présent, impératif, nom d'action) ;
- la phrase verbale (le verbe d'abord, le sujet à la damma ; le « il » est dans le verbe) ;
- le classement des mots connus en noms et en particules (أَيْنَ est un nom).

**Leçon 5** (`l05`) :
- les trois cas du nom : الرَّفْعُ (damma), النَّصْبُ (fatha, avec l'alif du tanwin : كِتَابًا, sans alif après ة), الْجَرُّ (kasra) ; les adjectifs مَرْفُوعٌ مَنْصُوبٌ مَجْرُورٌ ;
- le رَفْع, cas de base (les noms des phrases sans verbe vues jusque-là) ; le نَصْب n'est montré qu'avec قَرَأْتُ كِتَابًا / قَرَأْتُ كِتَابَ مُحَمَّدٍ (verbe conjugué non enseigné) ;
- الْإِضَافَةُ (annexion) :
  - le premier terme (الْمُضَافُ) perd son tanwin, n'a pas d'article, et varie selon son rôle (damma, fatha, kasra) ;
  - le second terme (الْمُضَافُ إِلَيْهِ) est toujours مَجْرُورٌ, avec ou sans article ;
  - l'ensemble est défini quand le second terme l'est (كِتَابُ الطَّالِبِ ≠ كِتَابُ طَالِبٍ) ;
  - le ة d'un premier terme se prononce « t » ;
  - une annexion à trois noms (اِبْنُ عَمِّ زَيْدٍ) ;
  - un nom sans tanwin en annexion : كِتَابُ عُمَرَ, فِي مَسَاجِدِ مَكَّةَ ;
  - الْمُضَافُ et الْمُضَافُ إِلَيْهِ comme termes ;
- كِتَابُ مَنْ هٰذَا؟ (« à qui est… ? », مَنْ invariable en second terme) ;
- النِّدَاءُ : يَا + nom sans tanwin (damma simple), la même particule pour un homme ou une femme, avec الْمُنَادَى ;
- تَحْتَ (nom de lieu, premier terme d'annexion) et هُنَاكَ ;
- أَكِتَابُ مُحَمَّدٍ هٰذَا؟ (ordre des mots dans la question, montré dans le dialogue) ;
- le vocabulaire de la famille et des titres, la voiture, le sac, la rue, Allah, le Coran, la Kaaba, le Messager, Médine (voir `items.json`) ;
- l'alif de liaison de اِبْنٌ (et de اِسْمٌ) après وَ ou un autre mot ;
- les pluriels de forme أَفْعَالٌ, des pluriels de personnes, des pluriels sans tanwin de forme فُعَلَاءُ / أَفْعِلَاءُ (et أَسْمَاءٌ / أَبْنَاءٌ avec tanwin).

**Leçon 6** (`l06`) :
- هٰذِهِ (féminin, singulier, proche ; choses et personnes), مَا هٰذِهِ ؟ / مَنْ هٰذِهِ ؟ ; تِلْكَ est seulement citée (féminin de ذٰلِكَ), sans exercice ;
- le genre : الْمُذَكَّرُ et الْمُؤَنَّثُ, les trois cas de noms féminins (une femme ou une femelle, un signe du féminin, féminin sans raison particulière) et les noms masculins (un homme, ou aucun signe) ;
- les trois signes du féminin : تَاءُ التَّأْنِيثِ الْمُتَحَرِّكَةُ (ة), أَلِفُ التَّأْنِيثِ الْمَقْصُورَةُ (ى), أَلِفُ التَّأْنِيثِ الْمَمْدُودَةُ (اء) ; une hamza finale n'est pas toujours un signe du féminin (مَاءٌ هَوَاءٌ غَدَاءٌ sont masculins) ; les noms à alif du féminin sont مَمْنُوعٌ مِنَ الصَّرْفِ ;
- former le féminin d'un nom de personne avec ة (طَالِبٌ → طَالِبَةٌ) ; l'accord de l'adjectif attribut et du pronom (هُوَ / هِيَ) avec le genre du sujet : الْغُرْفَةُ مَفْتُوحَةٌ ;
- les féminins sans signe : parties du corps qui vont par paire (la plupart), noms de femmes (أُمٌّ أُخْتٌ بِنْتٌ) ;
- les prénoms d'hommes en ة (حَمْزَةُ أُسَامَةُ طَلْحَةُ) : masculins, sans tanwin ;
- l'accord du démonstratif avec le premier terme d'une annexion (هٰذَا مِفْتَاحُ السَّيَّارَةِ) ;
- la préposition لِ (اللَّامُ الْمِلْكِيَّةُ) : le nom qui suit est مَجْرُورٌ ; لِ + الْ → لِلْ (لِلْمُدِيرِ, لِلَّهِ) ; لِمَنْ هٰذَا ؟ / لِمَنِ الْكِتَابُ ؟ ; différence entre كِتَابُ زَيْدٍ (annexion) et الْكِتَابُ لِزَيْدٍ ;
- les trois sortes de noms (démonstratif, interrogatif, nom propre) et de particules (حُرُوفُ الْجَرِّ, حَرْفُ الِاسْتِفْهَامِ, حَرْفُ النِّدَاءِ) ;
- le vocabulaire de la cuisine, de la ferme, du corps, de la famille et des adjectifs جَمِيلٌ سَرِيعٌ قَدِيمٌ مَرِيضٌ حَارٌّ, جِدًّا, أَيْضًا, الْحَمْدُ لِلَّهِ, الْمَشْرِقُ (voir `items.json`) ;
- les pluriels : en -āt (دَرَّاجَاتٌ, أُمَّهَاتٌ, أَخَوَاتٌ), de forme longue (مَلَاعِقُ, نَوَافِذُ, مَشَارِقُ, مَكَاوٍ), autres pluriels brisés (قُدُورٌ, أَرْجُلٌ, آذَانٌ, أُنُوفٌ, سِرَاعٌ), en -ūna (فَلَّاحُونَ, مُسْلِمُونَ) et noms collectifs (بَقَرٌ, دَجَاجٌ).

**Leçon 7** (`l07`) :
- تِلْكَ (féminin, singulier, éloigné ; choses et personnes), مَا تِلْكَ ؟ / مَنْ تِلْكَ ؟ ; les quatre démonstratifs du singulier (proche / loin × masculin / féminin), leur invariabilité, le moyen de les retenir (هٰ au début = proche, كَ à la fin = loin) et le « lām de l'éloignement » / « kāf d'adresse » ;
- اِسْمُ الْإِشَارَةِ (nom démonstratif) et الْمُشَارُ إِلَيْهِ (nom désigné), à ne pas confondre avec الْمُضَافُ إِلَيْهِ ;
- la phrase « démonstratif + premier terme d'une annexion » (ذٰلِكَ مِفْتَاحُ السَّيَّارَةِ) et le démonstratif en fin de question (أَسَاعَةُ عَبَّاسٍ هٰذِهِ؟, rappel du chapitre 5) ; groupe (هٰذِهِ السَّيَّارَةُ) ou phrase (هٰذِهِ سَيَّارَةٌ) ;
- قَرِيبٌ مِنْ / بَعِيدٌ مِنْ (avec مِنَ devant l'article), عَنْ seulement citée ; طَوِيلٌ / قَصِيرٌ et leur accord ; la forme مُفَعِّلٌ (مُدَرِّسٌ, مُمَرِّضٌ, مُؤَذِّنٌ : celui qui fait l'action) ;
- le vocabulaire : بَطَّةٌ, بَيْضَةٌ, حَدِيقَةٌ, مُمَرِّضَةٌ, مُؤَذِّنٌ, طَوِيلٌ, قَصِيرٌ (voir `items.json`) ;
- les pluriels : بَطٌّ et بَيْضٌ (noms collectifs), حَدَائِقُ, نُوقٌ, طِوَالٌ, قِصَارٌ, أَقْرِبَاءُ, بِعَادٌ (les trois derniers ajoutés aux mots قَرِيبٌ et بَعِيدٌ du chapitre 5 et à نَاقَةٌ du chapitre 6), مُمَرِّضَاتٌ, مُؤَذِّنُونَ.

**Leçon 8** (`l08`) :
- la phrase complète (`الْجُمْلَةُ الْمُفِيدَةُ`) : deux éléments, qui apportent une information et se suffisent ;
- la phrase nominale (`الْجُمْلَةُ الِاسْمِيَّةُ`) : `الْمُبْتَدَأُ` (en principe défini, au nominatif) et
  `الْخَبَرُ` (au nominatif ; un nom ou adjectif, « préposition + nom », ou un verbe) ; `زَيْدٌ خَرَجَ` est
  nominale ; l'accord du prédicat ;
- la phrase verbale (`الْجُمْلَةُ الْفِعْلِيَّةُ`) : `الْفِعْلُ` et `الْفَاعِلُ` (après le verbe, au nominatif) ;
  à l'impératif le sujet est caché ; les trois verbes `جَلَسَ كَتَبَ رَجَعَ` avec leurs quatre formes ;
- le substitutif (`الْبَدَلُ`, `الْمُبْدَلُ مِنْهُ`) : le test de la suppression, l'accord en genre, nombre et cas,
  `التَّوَابِعُ` ; le nom après un démonstratif est un `بَدَل` (analyse du Tome de Médine) ;
- demander un nom : `مَا اسْمُ الرَّجُلِ ؟` / `اِسْمُ الطَّبِيبِ سَعِيدٌ` ; rappel de `مِنْ أَيْنَ` ;
- les adverbes `الظُّرُوفُ` : `فَوْقَ تَحْتَ أَمَامَ خَلْفَ` (lieu) et `الْآنَ` (temps), noms en général
  à la fatha, suivis d'un nom à la kasra (annexion) ; tableau des trois cas ;
- le nom maqṣūr (`الِاسْمُ الْمَقْصُورُ`) : fin invisible, fatha avant le ى, cas sous-entendu, tanwin ;
- vocabulaire : `مُسْتَشْفًى عَبْدٌ سَبُّورَةٌ سِكِّينٌ مِحْرَابٌ حَاسُوبٌ كُرَةٌ أَمْرِيكَا أَلْمَانِيَا` ;
- pluriels : en -āt (`سَبُّورَاتٌ مُسْتَشْفَيَاتٌ`), de forme longue (`سَكَاكِينُ مَحَارِيبُ حَوَاسِيبُ`),
  `عِبَادٌ` ; `مَرْضَى` est cité dans une astuce (pas d'élément).

- seulement **aperçus** dans les dialogues, avec une astuce « Des petites formes à repérer » (rien n'est exigé en exercice) : les suffixes `ـهُ ـهِ ـكَ ـي`, les formes `نَجَحْتَ`, `أَسْكُنُ`, `تَسْكُنُ`, `يَرْفَعُ`, `مَعَ`, `قَبْلَ`, `مَا` + passé (négation), le complément d'objet à la fatha (`عُنْوَانَ الدَّرْسِ`) et l'adjectif épithète après le nom (`السَّيَّارَةُ الْجَمِيلَةُ`, astuce de `dialogue-4`) ;
- les pluriels : `أَسَابِيعُ أَمَاكِنُ عَنَاوِينُ صَنَابِيرُ أَصْدِقَاءُ`, `أَيَّامٌ دُرُوسٌ أَكْوَابٌ طُرُقٌ اِخْتِبَارَاتٌ صَلَوَاتٌ`, et ceux des adjectifs `كِبَارٌ صِغَارٌ حِزَانٌ فَرْحَى بِيضٌ`.

**Pas encore enseigné** (ne pas l'exiger dans un exercice) :
- les démonstratifs pluriels ;
- les autres pronoms (seuls هُوَ هِيَ أَنَا أَنْتَ sont vus) et les suffixes (صَدِيقِي, قَمِيصُكَ) ;
- les cas du nom et leurs fonctions : le sujet, le prédicat, le sujet du verbe, l'adverbe, le second terme d'annexion et le nom après une préposition sont vus (leçon 8) ; pas le complément d'objet : le نَصْب n'est montré qu'avec les adverbes et après قَرَأْتُ (et, sans exercice, dans les dialogues de la révision 1) ;
- l'interpellation d'un nom annexé (يَا عَبْدَ اللَّهِ) ou avec أَيُّهَا ;
- l'annexion « d'apparence » (الضَّارِبُ الرَّجُلِ) ;
- l'adjectif épithète placé après le nom (هٰذِهِ ذِكْرَى جَمِيلَةٌ) : seul l'adjectif attribut est vu (la révision 1 n'en donne qu'un aperçu, dans l'astuce de `dialogue-4`, sans exercice) ;
- le pluriel des adjectifs : seuls quelques-uns sont vus (سِرَاعٌ, et ceux de la révision 1) ;
- les autres prépositions (`بِ`, `مَعَ`, `عَنْ` ne sont qu'aperçues) ;
- les verbes conjugués (sauf les verbes cités au passé à la 3ᵉ personne du masculin singulier — chapitres 4 et 8, révision 1 — et leurs formes citées) ;

Le validateur refuse هٰذَا ou ذٰلِكَ devant un nom marqué féminin, et هٰذِهِ ou تِلْكَ devant un nom marqué masculin (sauf si deux éléments de genres différents s'écrivent pareil sans harakat, comme رَجُلٌ et رِجْلٌ).

  - `مَا` devant un verbe au passé = négation ; `مَعَ` et `قَبْلَ` suivis d'un nom au génitif ; suffixes `ـهُ / ـهِ`, `ـكَ`, `ـي` (aperçu) ; les préfixes `أَ` (« je ») et `تَ` (« tu ») dans `أَسْكُنُ` / `تَسْكُنُ` (aperçu) ;
  - formes féminines (`فَرِحَةٌ`, `حَزِينَةٌ`, `جَيِّدَةٌ`, `صَدِيقَةٌ`) et réponses (`وَعَلَيْكَ السَّلَامُ`, `وَرَحْمَةُ اللَّهِ`) ;
  - le sujet d'une phrase nominale « en principe défini » (rappel du chapitre 8) et la hamza finale de `مَاءٌ` (rappel du chapitre 6).
- **Nouvelle icône :** aucune (`طَرِيقٌ` utilise l'icône `road` du chapitre 5).
