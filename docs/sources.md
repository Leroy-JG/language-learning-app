# Sources et choix de contenu

Ce fichier garde la mémoire du contenu : d'où vient chaque leçon, ce qu'elle enseigne (une leçon
suivante ne peut s'appuyer que sur ce qui est déjà enseigné), et les choix faits quand l'app
s'écarte ou complète les supports du professeur. **À mettre à jour à chaque leçon.**

## Les supports du professeur

PDF en français d'un professeur (cours vidéo sur le Tome de Médine 1), fournis par l'utilisateur.
Ils **ne sont pas dans le dépôt** : le dépôt est public, et l'auteur autorise l'usage personnel mais
interdit la modification et l'usage commercial de ses supports. Pour une nouvelle leçon, demander à
l'utilisateur de joindre les PDF dans la conversation.

## Ce qui est déjà enseigné (cumulatif)

**Leçon 1** (`l01`) :
- les trois sortes de mots : nom, verbe, particule (définitions des grammairiens) ;
- le verbe : passé, présent ou futur (المُضَارِع), impératif ;
- هٰذَا (singulier, masculin, proche ; choses et personnes) ;
- pas de verbe « être » dans la phrase nominale ;
- l'alif suscrit (هٰذَا) ;
- les questions avec أَ, مَا (chose, animal), مَنْ (personne) ;
- les réponses نَعَمْ et لَا ;
- le tanwin = « un / une » ;
- les premiers pluriels (vus comme vocabulaire).

**Leçon 2** (`l02`) :
- ذٰلِكَ (éloigné) ;
- وَ (et) ;
- أَذٰلِكَ ؟ ;
- le classement des mots connus : noms interrogatifs et démonstratifs, particules interrogative, de réponse et de coordination ;
- les noms de matière (« du sucre », « du lait »).

**Leçon 3** (`l03`) :
- indéfini (نَكِرَةٌ) et défini (مَعْرِفَةٌ) ;
- le tanwin : son nom, ses trois formes, les noms propres, la pause ;
- l'article الْ, qui fait perdre le tanwin ;
- la phrase « le stylo est cassé » (adjectif attribut) ;
- la hamza de liaison :
  - en début de phrase ;
  - après وَ ;
  - مَنِ devant l'article ;
  - الِاسْمُ ;
  - la différence avec la hamza coupante ;
- les lettres lunaires et solaires (avec la shadda) ;
- le genre des noms :
  - ة marque le plus souvent le féminin, et sa prononciation (t / h) ;
  - les parties du corps qui vont par paire sont féminines pour la plupart.

**Leçon 4** (`l04`) :
- الْإِعْرَابُ : la terminaison change selon le rôle du mot (trois voyelles finales, avec ou sans tanwin) ;
- les prépositions (حُرُوفُ الْجَرِّ) :
  - فِي عَلَى مِنْ إِلَى avec leurs sens ;
  - le nom qui suit prend en général la kasra (◌ُ → ◌ِ, ◌ٌ → ◌ٍ) ;
  - مِنْ devient مِنَ devant l'article ;
  - le ى final de عَلَى et إِلَى ;
- la phrase sans verbe « nom défini + préposition + nom » (الْكِتَابُ عَلَى الْمَكْتَبِ) ;
- أَيْنَ (invariable) et مِنْ أَيْنَ ;
- les pronoms هُوَ هِيَ أَنَا أَنْتَ (et أَنْتِ, signalé) : ce sont des noms définis, هُوَ / هِيَ suivent le genre du nom remplacé ;
- les noms propres (الْعَلَمُ) et les quatre sortes de noms définis vues jusqu'ici (nom propre, démonstratif, avec الْ, pronom) ;
- le tanwin (définition, marque du nom) et plusieurs marques du nom, dont trois sont citées (tanwin, article, pouvoir suivre une préposition) ;
- les noms privés de tanwin (مَمْنُوعٌ مِنَ الصَّرْفِ) :
  - la plupart des noms propres féminins, et les pluriels de forme « longue » (مَدَارِسُ, مَرَاحِيضُ…) ;
  - ils prennent une fatha après une préposition (فِي مَكَّةَ) ;
  - les noms étrangers en alif long ne changent pas à l'écrit (فَرَنْسَا) ;
- les noms de lieux en مَ (اِسْمُ الْمَكَانِ), repérés dans مَسْجِدٌ مَكْتَبٌ مَطْبَخٌ مَدْرَسَةٌ ;
- le verbe خَرَجَ et le verbe ذَهَبَ (passé, présent, impératif, nom d'action) ;
- la phrase verbale (le verbe d'abord, le sujet à la damma ; le « il » est dans le verbe) ;
- le classement des mots connus en noms et en particules (أَيْنَ est un nom).

**Leçon 5** (`l05`) :
- les trois cas du nom : الرَّفْعُ (damma), النَّصْبُ (fatha, avec l'alif du tanwin : كِتَابًا, sans alif après ة), الْجَرُّ (kasra) ; les adjectifs مَرْفُوعٌ مَنْصُوبٌ مَجْرُورٌ ;
- le رَفْع, cas de base (les noms des phrases sans verbe vues jusque-là) ; le نَصْب n'est montré qu'avec قَرَأْتُ كِتَابًا / قَرَأْتُ كِتَابَ مُحَمَّدٍ (verbe conjugué non enseigné) ;
- الْإِضَافَةُ (annexion) :
  - le premier terme (الْمُضَافُ) perd son tanwin, n'a pas d'article, et varie selon son rôle (damma, fatha, kasra) ;
  - le second terme (الْمُضَافُ إِلَيْهِ) est toujours مَجْرُورٌ, avec ou sans article ;
  - l'ensemble est défini quand le second terme l'est (كِتَابُ الطَّالِبِ ≠ كِتَابُ طَالِبٍ) ;
  - le ة d'un premier terme se prononce « t » ;
  - une annexion à trois noms (اِبْنُ عَمِّ زَيْدٍ) ;
  - un nom sans tanwin en annexion : كِتَابُ عُمَرَ, فِي مَسَاجِدِ مَكَّةَ ;
  - الْمُضَافُ et الْمُضَافُ إِلَيْهِ comme termes ;
- كِتَابُ مَنْ هٰذَا؟ (« à qui est… ? », مَنْ invariable en second terme) ;
- النِّدَاءُ : يَا + nom sans tanwin (damma simple), la même particule pour un homme ou une femme, avec الْمُنَادَى ;
- تَحْتَ (nom de lieu, premier terme d'annexion) et هُنَاكَ ;
- أَكِتَابُ مُحَمَّدٍ هٰذَا؟ (ordre des mots dans la question, montré dans le dialogue) ;
- le vocabulaire de la famille et des titres, la voiture, le sac, la rue, Allah, le Coran, la Kaaba, le Messager, Médine (voir `items.json`) ;
- l'alif de liaison de اِبْنٌ (et de اِسْمٌ) après وَ ou un autre mot ;
- les pluriels de forme أَفْعَالٌ, des pluriels de personnes, des pluriels sans tanwin de forme فُعَلَاءُ / أَفْعِلَاءُ (et أَسْمَاءٌ / أَبْنَاءٌ avec tanwin).

**Leçon 6** (`l06`) :
- هٰذِهِ (féminin, singulier, proche ; choses et personnes), مَا هٰذِهِ ؟ / مَنْ هٰذِهِ ؟ ; تِلْكَ est seulement citée (féminin de ذٰلِكَ), sans exercice ;
- le genre : الْمُذَكَّرُ et الْمُؤَنَّثُ, les trois cas de noms féminins (une femme ou une femelle, un signe du féminin, féminin sans raison particulière) et les noms masculins (un homme, ou aucun signe) ;
- les trois signes du féminin : تَاءُ التَّأْنِيثِ الْمُتَحَرِّكَةُ (ة), أَلِفُ التَّأْنِيثِ الْمَقْصُورَةُ (ى), أَلِفُ التَّأْنِيثِ الْمَمْدُودَةُ (اء) ; une hamza finale n'est pas toujours un signe du féminin (مَاءٌ هَوَاءٌ غَدَاءٌ sont masculins) ; les noms à alif du féminin sont مَمْنُوعٌ مِنَ الصَّرْفِ ;
- former le féminin d'un nom de personne avec ة (طَالِبٌ → طَالِبَةٌ) ; l'accord de l'adjectif attribut et du pronom (هُوَ / هِيَ) avec le genre du sujet : الْغُرْفَةُ مَفْتُوحَةٌ ;
- les féminins sans signe : parties du corps qui vont par paire (la plupart), noms de femmes (أُمٌّ أُخْتٌ بِنْتٌ) ;
- les prénoms d'hommes en ة (حَمْزَةُ أُسَامَةُ طَلْحَةُ) : masculins, sans tanwin ;
- l'accord du démonstratif avec le premier terme d'une annexion (هٰذَا مِفْتَاحُ السَّيَّارَةِ) ;
- la préposition لِ (اللَّامُ الْمِلْكِيَّةُ) : le nom qui suit est مَجْرُورٌ ; لِ + الْ → لِلْ (لِلْمُدِيرِ, لِلَّهِ) ; لِمَنْ هٰذَا ؟ / لِمَنِ الْكِتَابُ ؟ ; différence entre كِتَابُ زَيْدٍ (annexion) et الْكِتَابُ لِزَيْدٍ ;
- les trois sortes de noms (démonstratif, interrogatif, nom propre) et de particules (حُرُوفُ الْجَرِّ, حَرْفُ الِاسْتِفْهَامِ, حَرْفُ النِّدَاءِ) ;
- le vocabulaire de la cuisine, de la ferme, du corps, de la famille et des adjectifs جَمِيلٌ سَرِيعٌ قَدِيمٌ مَرِيضٌ حَارٌّ, جِدًّا, أَيْضًا, الْحَمْدُ لِلَّهِ, الْمَشْرِقُ (voir `items.json`) ;
- les pluriels : en -āt (دَرَّاجَاتٌ, أُمَّهَاتٌ, أَخَوَاتٌ), de forme longue (مَلَاعِقُ, نَوَافِذُ, مَشَارِقُ, مَكَاوٍ), autres pluriels brisés (قُدُورٌ, أَرْجُلٌ, آذَانٌ, أُنُوفٌ, سِرَاعٌ), en -ūna (فَلَّاحُونَ, مُسْلِمُونَ) et noms collectifs (بَقَرٌ, دَجَاجٌ).

**Leçon 7** (`l07`) :
- تِلْكَ (féminin, singulier, éloigné ; choses et personnes), مَا تِلْكَ ؟ / مَنْ تِلْكَ ؟ ; les quatre démonstratifs du singulier (proche / loin × masculin / féminin), leur invariabilité, le moyen de les retenir (هٰ au début = proche, كَ à la fin = loin) et le « lām de l'éloignement » / « kāf d'adresse » ;
- اِسْمُ الْإِشَارَةِ (nom démonstratif) et الْمُشَارُ إِلَيْهِ (nom désigné), à ne pas confondre avec الْمُضَافُ إِلَيْهِ ;
- la phrase « démonstratif + premier terme d'une annexion » (ذٰلِكَ مِفْتَاحُ السَّيَّارَةِ) et le démonstratif en fin de question (أَسَاعَةُ عَبَّاسٍ هٰذِهِ؟, rappel du chapitre 5) ; groupe (هٰذِهِ السَّيَّارَةُ) ou phrase (هٰذِهِ سَيَّارَةٌ) ;
- قَرِيبٌ مِنْ / بَعِيدٌ مِنْ (avec مِنَ devant l'article), عَنْ seulement citée ; طَوِيلٌ / قَصِيرٌ et leur accord ; la forme مُفَعِّلٌ (مُدَرِّسٌ, مُمَرِّضٌ, مُؤَذِّنٌ : celui qui fait l'action) ;
- le vocabulaire : بَطَّةٌ, بَيْضَةٌ, حَدِيقَةٌ, مُمَرِّضَةٌ, مُؤَذِّنٌ, طَوِيلٌ, قَصِيرٌ (voir `items.json`) ;
- les pluriels : بَطٌّ et بَيْضٌ (noms collectifs), حَدَائِقُ, نُوقٌ, طِوَالٌ, قِصَارٌ, أَقْرِبَاءُ, بِعَادٌ (les trois derniers ajoutés aux mots قَرِيبٌ et بَعِيدٌ du chapitre 5 et à نَاقَةٌ du chapitre 6), مُمَرِّضَاتٌ, مُؤَذِّنُونَ.

**Leçon 8** (`l08`) :
- la phrase complète (`الْجُمْلَةُ الْمُفِيدَةُ`) : deux éléments, qui apportent une information et se suffisent ;
- la phrase nominale (`الْجُمْلَةُ الِاسْمِيَّةُ`) : `الْمُبْتَدَأُ` (en principe défini, au nominatif) et
  `الْخَبَرُ` (au nominatif ; un nom ou adjectif, « préposition + nom », ou un verbe) ; `زَيْدٌ خَرَجَ` est
  nominale ; l'accord du prédicat ;
- la phrase verbale (`الْجُمْلَةُ الْفِعْلِيَّةُ`) : `الْفِعْلُ` et `الْفَاعِلُ` (après le verbe, au nominatif) ;
  à l'impératif le sujet est caché ; les trois verbes `جَلَسَ كَتَبَ رَجَعَ` avec leurs quatre formes ;
- le substitutif (`الْبَدَلُ`, `الْمُبْدَلُ مِنْهُ`) : le test de la suppression, l'accord en genre, nombre et cas,
  `التَّوَابِعُ` ; le nom après un démonstratif est un `بَدَل` (analyse du Tome de Médine) ;
- demander un nom : `مَا اسْمُ الرَّجُلِ ؟` / `اِسْمُ الطَّبِيبِ سَعِيدٌ` ; rappel de `مِنْ أَيْنَ` ;
- les adverbes `الظُّرُوفُ` : `فَوْقَ تَحْتَ أَمَامَ خَلْفَ` (lieu) et `الْآنَ` (temps), noms en général
  à la fatha, suivis d'un nom à la kasra (annexion) ; tableau des trois cas ;
- le nom maqṣūr (`الِاسْمُ الْمَقْصُورُ`) : fin invisible, fatha avant le ى, cas sous-entendu, tanwin ;
- vocabulaire : `مُسْتَشْفًى عَبْدٌ سَبُّورَةٌ سِكِّينٌ مِحْرَابٌ حَاسُوبٌ كُرَةٌ أَمْرِيكَا أَلْمَانِيَا` ;
- pluriels : en -āt (`سَبُّورَاتٌ مُسْتَشْفَيَاتٌ`), de forme longue (`سَكَاكِينُ مَحَارِيبُ حَوَاسِيبُ`),
  `عِبَادٌ` ; `مَرْضَى` est cité dans une astuce (pas d'élément).

**Leçon 9** (`l09`) : l'adjectif (`النَّعْتُ`, `الْمَنْعُوتُ`) qui s'accorde avec le nom en genre, défini ou indéfini et cas ; « le livre neuf » et « le livre est neuf » ; les adjectifs d'état sans tanwin (`كَسْلَانُ`, `جَوْعَانُ`…) ; les langues, les fruits, `هُنَا`, `عِنْدَ`, `يَوْمٌ`, `كَبِيرٌ`, `صَغِيرٌ`, `سَهْلٌ`, `كُوبٌ` et le texte du livre « لِمَنْ تِلْكَ السَّيَّارَةُ الْجَمِيلَةُ ؟ » (voir `l09/items.json` et `l09/chapter.json` ; les notes détaillées de cette leçon ne sont pas dans ce fichier).

**Révision 1** (`r01`, chapitre de révision placé après la leçon 9 ; pas de numéro, libellé « Révision 1 ») :
- sept rappels sans nouvelle carte (`revue-1` à `revue-7`, type `review`) : démonstratifs, interrogatifs (`أَ مَنْ مَا أَيْنَ`, avec `لِلْعَاقِلِ` / `لِغَيْرِ الْعَاقِلِ`), noms définis / indéfinis et prénoms, genre, prépositions, trois cas, phrase nominale / verbale et trois formes du verbe ;

- `مَاذَا` (« qu'y a-t-il… ? ») : `مَا` + `ذَا` ; réponse par le nom seul, ou `عَلَى الْمَكْتَبِ كِتَابٌ` (sujet indéfini après « préposition + nom ») ;
- `لِمَاذَا` (« pourquoi ? ») et `لِأَنَّهُ` (« parce que ») ;
- les jours de la semaine (`يَوْمُ الْأَحَدِ`… `يَوْمُ السَّبْتِ`) et `أُسْبُوعٌ` (`يَوْمٌ` est présenté au chapitre 9) ;
- vocabulaire : `دَرْسٌ اِخْتِبَارٌ عُنْوَانٌ وَرَقٌ`, `فَرِحٌ حَزِينٌ جَيِّدٌ` (`سَهْلٌ كُوبٌ كَبِيرٌ صَغِيرٌ كَسْلَانُ` sont ceux du chapitre 9), `صَلَاةٌ فَجْرٌ صُنْبُورٌ أَبْيَضُ طَرِيقٌ صَدِيقٌ`, `خَيْرٌ حَسَنًا ثُمَّ هَيَّا كَيْفَ الْيَوْمَ`, `السَّلَامُ عَلَيْكَ` / `عَلَيْكَ السَّلَامُ`, `كَيْفَ حَالُكَ؟`, `مَرْحَبًا بِكَ` ;
- 13 verbes (passé à la 3ᵉ personne du masculin singulier, avec leurs quatre formes dans une astuce) : `نَجَحَ فَشِلَ رَاجَعَ حَفِظَ رَفَعَ سَكَنَ` et `اِسْتَيْقَظَ قَامَ تَوَضَّأَ لَبِسَ لَقِيَ أَسْرَعَ تَأَخَّرَ` ;
- seulement **aperçus** dans les dialogues, avec une astuce « Des petites formes à repérer » (rien n'est exigé en exercice ; l'adjectif épithète, lui, est enseigné au chapitre 9) : les suffixes `ـهُ ـهِ ـكَ ـي`, les formes `نَجَحْتَ`, `أَسْكُنُ`, `تَسْكُنُ`, `يَرْفَعُ`, `مَعَ`, `قَبْلَ`, `مَا` + passé (négation), le complément d'objet à la fatha (`عُنْوَانَ الدَّرْسِ`) ;
- les pluriels : `أَسَابِيعُ أَمَاكِنُ عَنَاوِينُ صَنَابِيرُ أَصْدِقَاءُ`, `أَيَّامٌ دُرُوسٌ أَكْوَابٌ طُرُقٌ اِخْتِبَارَاتٌ صَلَوَاتٌ`, et ceux des adjectifs `كِبَارٌ صِغَارٌ حِزَانٌ فَرْحَى بِيضٌ`.

**Leçon 10** (`l10`) : les pronoms (`الضَّمَائِرُ`) :
- le pronom (`الضَّمِيرُ`) : un nom, toujours défini, à terminaison invariable ; pronoms isolés (`الْمُنْفَصِلُ`) et affixes (`الْمُتَّصِلُ`) ; les trois personnes (`الْمُتَكَلِّمُ`, `الْمُخَاطَبُ`, `الْغَائِبُ`) ;
- les 12 pronoms isolés du nominatif (`أَنَا نَحْنُ أَنْتَ أَنْتِ أَنْتُمَا أَنْتُمْ أَنْتُنَّ هُوَ هِيَ هُمَا هُمْ هُنَّ`), le duel et les terminaisons `ـمَا` / `ـمْ` / `ـنَّ`, le pronom comme sujet de la phrase nominale ; les pronoms isolés de l'accusatif (`إِيَّاكَ`, `إِيَّاهُ`) seulement cités ;
- les 12 pronoms affixes du génitif (`ـِي ـنَا ـكَ ـكِ ـكُمَا ـكُمْ ـكُنَّ ـهُ ـهَا ـهُمَا ـهُمْ ـهُنَّ`) : collés à un nom (plus de tanwin ni d'article, `ة` → `ت`, le pronom suit le possesseur) ou à une préposition (`مِنْ فِي لِ عَلَى إِلَى مَعَ عِنْدَ` : `لِ` → `لَ`, `يَّ`, `مِنِّي`, `ى` → `ي`, `ـهِ` après une kasra ou un `ي`) ;
- `أَبٌ` et `أَخٌ` devant un pronom affixe (`أَبُوكَ` / `أَبِي` / `كِتَابُ أَبِيهِ`) ;
- « avoir » : `لِي أَخٌ`, `عِنْدِي كِتَابٌ`, la question avec `أَ`, la négation `مَا عِنْدِي…` ;
- vocabulaire : `أَخٌ زَوْجٌ طِفْلٌ زَمِيلٌ فَتًى وَاحِدٌ مَعَ` ; `الْكُوَيْتُ الْعِرَاقُ الْأُرْدِيَّةُ الْيَابَانِيَّةُ` ; les phrases `مَا اسْمُكَ؟ اِسْمِي مُحَمَّدٌ. مَا لُغَتُكَ؟` ;
- pluriels : `زُمَلَاءُ أَزْوَاجٌ أَطْفَالٌ فِتْيَةٌ إِخْوَةٌ` et ceux des termes de grammaire (`الْمُتَكَلِّمُونَ`, `الضَّمَائِرُ`…) ;
- seulement **aperçus** (astuce « Des petites formes à repérer », rien n'est exigé en exercice) : la particule `بِ` (`بِالْجَامِعَةِ`), `الَّذِي`, les formes `ذَهَبْتُ` / `أَذَهَبْتَ`.

**Leçon 11** (`l11`) : variable et invariable, le nom suivi de `◌ِي`, `ـهُ` → `ـهِ`, « aimer » :
- le nom variable (`الْمُعْرَبُ`) : la base du nom ; le nom invariable (`الْمَبْنِيُّ`) : pronoms, démonstratifs et interrogatifs **que l'on connaît** (le duel des démonstratifs et `أَيٌّ` sont variables : seulement annoncés) ; les particules sont toutes invariables, le verbe au passé et l'impératif aussi, le présent est « en général » variable ; un nom invariable a pourtant un rôle (sujet, second terme d'annexion) ;
- le nom suivi de `◌ِي` : la kasra qui précède le `ي` n'est pas un signe du cas (on ne dit pas `مَجْرُورٌ` à cause d'elle) ; le cas est « sous-entendu », comme pour le nom maqṣūr, et se déduit du rôle (sujet de phrase nominale, sujet du verbe, après une préposition ou `مَعَ`) ; `كُرْسِيِّي` ;
- la règle complète de `هَاءُ الْغَائِبِ` : `ـهُ ـهُمَا ـهُمْ ـهُنَّ` deviennent `ـهِ ـهِمَا ـهِمْ ـهِنَّ` juste après une kasra ou un `ي` sans voyelle (pas après un sukun : `مِنْهُ`) ; `ـهَا` ne change jamais ;
- vocabulaire : `أَحَبَّ` (avec ses quatre formes dans une astuce), `يُحِبُّ`, `أُحِبُّ`, `أَحَدٌ` (dans une question ou après une négation : `مَا فِيهِ أَحَدٌ`), `النَّبِيُّ` ;
- le texte du livre « بَيْتِي » (deux dialogues) et les exercices 1 (`فِيهِ` / `فِيهَا`) et 2 (`أُحِبُّ …`) ;
- seulement **aperçu** (aucun exercice) : l'accusatif de ce qu'on aime (`أُحِبُّ اللَّهَ`, `أُحِبُّ اللُّغَةَ الْعَرَبِيَّةَ`) ; un exercice peut en revanche demander le sens de la phrase.

**Leçon 12** (`l12`) : les noms interrogatifs, le verbe au féminin, parler à une femme, la salutation complète :
- les quatre noms interrogatifs `مَا` `مَنْ` `أَيْنَ` `كَيْفَ` (`أَسْمَاءُ الِاسْتِفْهَامِ`) : invariables, en tête de la question (une préposition ou `وَ` peut les précéder) ; `كَيْفَ` : l'état, la manière ; `مَاذَا` et `لِمَاذَا` rappelés ;
- le verbe au passé avec un sujet féminin : le `تْ` du féminin (`تَاءُ التَّأْنِيثِ السَّاكِنَةُ`, une particule, pas un pronom) ; sa kasra devant l'article ou un mot à hamza de liaison (`جَلَسَتِ الطَّالِبَةُ`) ; `ذَهَبَتْ` `خَرَجَتْ` `جَلَسَتْ` ;
- parler à une femme : `كَ` → `كِ`, `أَنْتَ` → `أَنْتِ`, accord du nom attribut (`أَأَنْتِ طَبِيبَةٌ يَا أُخْتِي؟`) ; `كَيْفَ حَالُكِ؟` `مَا اسْمُكِ؟` `مِنْ أَيْنَ أَنْتِ؟` ;
- la salutation complète (`السَّلَامُ عَلَيْكِ وَرَحْمَةُ اللَّهِ وَبَرَكَاتُهُ`) et sa réponse ;
- vocabulaire : `سَلَامٌ` `رَحْمَةٌ` `بَرَكَةٌ` `حَالٌ` `فَتَاةٌ` `زَمِيلَةٌ` `مُوَجِّهٌ` `الْمُتَوَسِّطَةُ` `وِلَادَةٌ` `شَجَرَةٌ` `الرِّيَاضُ` ; pluriels `رَحَمَاتٌ` `بَرَكَاتٌ` `أَحْوَالٌ` `فَتَيَاتٌ` `وِلَادَاتٌ` `شَجَرٌ` `مُوَجِّهُونَ` ;
- le dialogue du livre (deux activités) et les exercices 1 à 5 ;
- seulement **aperçus** (astuce « Des petites formes à repérer », rien n'est exigé en exercice) : `الَّتِي` et `الَّذِي` (« qui, que »), `بِالْجَامِعَةِ`.

**Pas encore enseigné** (ne pas l'exiger dans un exercice) :
- les démonstratifs pluriels ;
- les pronoms affixes du nominatif et de l'accusatif (ils s'attachent aux verbes) et les pronoms isolés de l'accusatif (`إِيَّاكَ`) ;
- les cas du nom et leurs fonctions : le sujet, le prédicat, le sujet du verbe, l'adverbe, le second terme d'annexion et le nom après une préposition sont vus (leçon 8) ; pas le complément d'objet : le نَصْب n'est montré qu'avec les adverbes et après قَرَأْتُ (et, sans exercice, dans les dialogues de la révision 1 et dans les phrases `أُحِبُّ …` de la leçon 11) ;
- l'interpellation d'un nom annexé (يَا عَبْدَ اللَّهِ) ou avec أَيُّهَا ;
- l'annexion « d'apparence » (الضَّارِبُ الرَّجُلِ) ;
- le pluriel des adjectifs : seuls quelques-uns sont vus (سِرَاعٌ, ceux des chapitres 9 et de la révision 1) ;
- les autres prépositions (`بِ` et `عَنْ` ne sont qu'aperçues ; `مَعَ` est enseigné au chapitre 10) ;
- les verbes conjugués (sauf les verbes cités au passé à la 3ᵉ personne du masculin singulier — chapitres 4 et 8, révision 1 — et leurs formes citées) ;

Le validateur refuse هٰذَا ou ذٰلِكَ devant un nom marqué féminin, et هٰذِهِ ou تِلْكَ devant un nom marqué masculin (sauf si deux éléments de genres différents s'écrivent pareil sans harakat, comme رَجُلٌ et رِجْلٌ).

- **Explications ajoutées (données à l'oral, absentes des PDF) :**
  - la kasra devient kasratan sur un nom indéfini après une préposition ;
  - مِنْ → مِنَ devant l'article, le ى de عَلَى et إِلَى, le nom مَجْرُورٌ ;
  - les lieux en مَ (اِسْمُ الْمَكَانِ), la famille مُدَرِّسٌ / مَدْرَسَةٌ ;
  - les marques du nom (tanwin, article, préposition devant le mot : il en existe d'autres), et le fait que les pronoms sont des noms définis ;
  - la fatha reste un cas de مَجْرُورٌ ; les noms privés de tanwin reprennent la kasra avec l'article ou en annexion ;
  - مِنْ / مَنْ (mêmes lettres) et مِنَ الْ / مَنِ الْ ;
  - la voyelle longue finale de فِي, عَلَى, إِلَى devient brève devant l'article ;
  - le mot interrogatif ouvre la phrase (أَيْنَ ذَهَبَ ؟, مَنْ خَرَجَ ؟) ;
  - « -ūna » devient « -īna » après une préposition ;
  - سَمَاءٌ se trouve aussi au masculin en arabe classique ;
  - les conséquences de « privé de tanwin » (fatha après une préposition, noms en ا, pluriels de forme longue) ;
  - أَيْنَ, هٰذَا et ذٰلِكَ ne changent jamais de terminaison ;
  - عَلَمٌ veut aussi dire « drapeau », الْجُمُعَةُ vient de جَمَعَ, ذَهَبَ / ذَهَبٌ ont les mêmes lettres ;
  - عُمَرُ et أَحْمَدُ sont des prénoms d'hommes sans tanwin.

  - le second terme d'une annexion après un adverbe est au génitif : kasra ou tanwin, fatha pour un nom privé de tanwin (`عُمَرَ`) ; `مُوسَى` et `عِيسَى` n'ont pas de tanwin (noms propres étrangers) ;
  - `عِبَادٌ` (serviteurs d'Allah) et `عَبِيدٌ` (esclaves) ;
  - dans `اِذْهَبْ يَا زَيْدُ`, `زَيْدُ` est la personne appelée, pas le sujet ;
  - `مَا اسْمُ… ؟` : littéralement « qu'est-ce que le nom de… ? », l'alif de liaison de `اسْمُ` ;
  - la voyelle de l'alif de l'impératif suit la dernière lettre du présent (damma → damma, sinon kasra) ;
  - le test de la suppression est une astuce (il ne vaut pas définition) ;
  - après une préposition, l'adverbe prend la kasra (`مِنْ فَوْقِ الْمَكْتَبِ`) ;
  - `الْآنَ` ne change pas de terminaison ;
  - le tanwin du nom maqṣūr (`مُسْتَشْفًى`, écrit avant le ى) et les noms sans tanwin (`ذِكْرَى`, `مَرْضَى`) ;
  - `عَبْدُ اللَّهِ`, le mihrab.
- **Pas de nouvelle icône** : le chapitre n'ajoute aucune image.
- **Lien avec le chapitre 7 :** le nom qui suit un démonstratif s'appelle `الْمُشَارُ إِلَيْهِ` au chapitre 7 (d'après ce qu'il désigne) et `بَدَل` au chapitre 8 (d'après son rôle) : une note de `l08/grammar-4` fait le lien.

- **Support :** un seul PDF de 13 pages (cours 12 : `أَسْمَاءُ الِاسْتِفْهَامِ`, `كَيْفَ`, `عَلَامَةُ التَّأْنِيثِ فِي الْفِعْلِ الْمَاضِي`, texte du livre, exercices 1 à 5, vocabulaire nouveau).
- **Exercices du livre repris :**
  - texte du livre (dialogue de Suʿād et d'une jeune fille) → `dialogue-1` (lignes 1 à 12) et `dialogue-2` (lignes 13 à 28), avec une astuce « Des petites formes à repérer » (`الَّتِي`, `الَّذِي`, `بِالْجَامِعَةِ`) ; la vocalisation du PDF est incomplète, elle a été reconstituée ; deux locutrices, donc la même voix `f1` (une seule voix féminine existe) ;
  - exercice 1 (lecture) → `practice-3` (phrases 3 et 4 en questions de compréhension, après l'enseignement du `تْ` ; phrases 5 et 8 à 9 en exercices ; phrase 6 adaptée) et `grammar-4` (phrases 1 à 5) ;
  - exercice 2 (changer le mot qui interpelle) → `grammar-4` et `practice-3` (astuces `compare`), en plus d'exercices sur les phrases (jamais deux formes `كَ` / `كِ` dans un même choix : identiques sans harakat) ;
  - exercice 3 (mettre le sujet au féminin) → `practice-2` ; exercice 4 (`جَلَسَتِ الطَّالِبَةُ`) → `grammar-3` ;
  - exercice 5 (`الَّذِي` / `الَّتِي`) → `practice-4`, en lecture et en exercices sur `مَنِ` / `لِمَنِ` seulement (aucun exercice sur `الَّذِي` / `الَّتِي`).
- **Écarts avec le PDF :**
  - exercice 1, phrase 6 (`أَهٰذَا قَلَمُكَ يَا مُحَمَّدُ؟ لَا. هٰذَا قَلَمُكَ أَنْتَ.`) : la réponse se contredit ; l'app emploie `لَا. هٰذَا قَلَمِي` ; la phrase 7 (`تِلْكَ السَّيَّارَةُ …`) n'est pas reprise (`الَّتِي` n'est qu'aperçu) ;
  - exercice 1, phrase 2 : le PDF écrit `كيف حالك يا أمي` sans voyelles ; l'app met `حَالُكِ` (à une femme) ;
  - exercice 2, phrases 2, 6 et 7 : non reprises (`أُسْتَاذَتِي`, `خَالَتِي`, `عَمَّتِي` ne sont pas enseignés) ;
  - `هٰذِهِ شَجَرَةٌ طَيِّبَةٌ` (exemple du vocabulaire) → `هٰذِهِ شَجَرَةٌ كَبِيرَةٌ` (`طَيِّبٌ` n'est pas enseigné) ;
  - `الْمُتَوَسِّطَةُ` (sans traduction dans le PDF) : « le collège » ;
  - le professeur dit que le nom interrogatif « débute toujours la phrase » : l'app écrit « se place en tête de la question » et cite la préposition et `وَ` devant lui (`مِنْ أَيْنَ`, `لِمَنْ`, `وَأَيْنَ`) ; il est dit invariable pour « les quatre que l'on connaît » (comme au chapitre 11) ;
  - `هٰذَا` écrit avec l'alif suscrit, comme dans tout le cours ; `اِسْمِي` avec la kasra en début de phrase, `مَا اسْمُكِ` sans.
- **Corrections après relecture :**
  - un féminin de chose (`سَيَّارَةٌ`) admet un verbe sans `تْ` (facultatif, Ibn ʿAqīl) : aucun distracteur n'oppose `خَرَجَ` à `السَّيَّارَةُ` ; les exercices n'emploient que des féminins réels (`الْمُدَرِّسَةُ`, `الطَّالِبَةُ`, `الطَّبِيبَةُ`, noms de femmes) et l'astuce le dit ;
  - la kasra du `ت` apparaît aussi devant un mot à hamza de liaison, pas seulement devant l'article ;
  - `مَاذَا` et `لِمَاذَا` sont déjà enseignés (révision 1) : l'astuce ne dit plus qu'il n'y a pas d'autres mots d'interrogation connus ;
  - la kasra de `مَنِ` n'est pas un changement de cas (enchaînement, chapitre 3) ;
  - `الْمُدَرِّسَةُ` et `الْمَدْرَسَةِ` s'écrivent pareil sans harakat : jamais dans le même exercice d'étiquettes ;
  - `فَتَاةٌ` : jamais en face de `بِنْتٌ` (« une fille ») dans un QCM ; la réponse « C'est une fille » est acceptée pour une image de fille.
- **Réponses acceptées en plus :** l'ordre sujet d'abord pour les phrases verbales (`أُمِّي ذَهَبَتْ إِلَى الْمُسْتَشْفَى`) ; `هٰذَا لِلْمُدَرِّسِ` / `هٰذِهِ لِزَوْجِ أُخْتِي`.
- **Choix de contenu :**
  - `حَالٌ` : genre `m`, avec la précision que les dictionnaires (Lisān al-ʿArab, al-Muʿjam al-Wasīṭ) l'admettent aussi au féminin ;
  - `الرِّيَاضُ` (une ville) : pas de `gender`, comme les pays ;
  - `شَجَرٌ` : nom collectif ; `شَجَرَةٌ` en est le nom d'unité ;
  - `رَحْمَةٌ` : pluriel `رَحَمَاتٌ` (forme du PDF) ;
  - `زَمِيلَةٌ` : pas de pluriel donné (le PDF n'en donne pas) ;
  - le `تْ` du féminin n'est pas un item (le genre du mot `تَاءٌ` n'est pas certain) : il n'est nommé que dans une astuce ;
  - `ذَهَبَتْ` et `ذَهَبْتُ` s'écrivent pareil sans harakat : `ذَهَبْتُ` n'est pas un item (seulement aperçu au chapitre 10), donc aucun QCM ne les oppose.
- **Explications ajoutées (données à l'oral, absentes du PDF) :**
  - le `تْ` est obligatoire avec une femme, facultatif avec un féminin de chose ; différence avec le `تُ` de `ذَهَبْتُ` (pronom, voyelle sur le `ت`) ; sans sujet écrit, le verbe se traduit « il » / « elle » ;
  - même règle que `مَنْ` → `مَنِ` pour la kasra du `ت` : on ne prononce pas deux sukūn de suite ;
  - `كَ` / `كِ` s'écrivent pareil sans voyelles : le mot qui interpelle dit à qui l'on parle ;
  - `مَا` : `لِغَيْرِ الْعَاقِلِ` / `مَنْ` : `لِلْعَاقِلِ` / `أَيْنَ` : `لِلْمَكَانِ` / `كَيْفَ` : `لِلْحَالِ وَالْكَيْفِيَّةِ` ;
  - salutation complète et réponse « par la même formule ou une meilleure » (sourate 4, verset 86) ;
  - `الرِّيَاضُ` est le pluriel de `رَوْضَةٌ` (« jardin ») ; `الْمُتَوَسِّطَةُ` : cycle entre l'école primaire et le lycée dans le système saoudien ; `مُوَجِّهٌ` vient de `وَجَّهَ` ; `سَلَامٌ` et `مُسْلِمٌ` de la même famille.
